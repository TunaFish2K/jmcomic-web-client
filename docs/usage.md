# 使用说明

## 阅读器设置

| 设置 | 可选值 | 默认值 |
| --- | --- | --- |
| 阅读方向 | 左右滚动、上下滚动 | 左右滚动 |
| 自动吸附 | 开启、关闭 | 开启 |
| 无缝模式 | 开启、关闭 | 关闭 |
| 懒加载范围 | 前后各 1 至 12 页 | 前后各 4 页 |
| 信息栏 | 显示、隐藏 | 显示在底部 |
| 自动翻译 | 开启、关闭 | 关闭 |
| 预翻译范围 | 当前页前后各 0 至 5 页 | 前后各 2 页 |
| LLM 并发 | 1 至 6 | 1 |
| 思考 | 跟随服务、关闭、开启 | 关闭 |
| 思考等级 | Minimal、Low、Medium、High、XHigh、Max | Medium |
| 翻译风格提示词 | 自定义多行文本或留空 | 成人向本地化模板 |
| 内容处理（破限）提示词 | 自定义多行文本或留空 | 忠实内容处理模板 |

所有设置都保存在当前浏览器中。无缝模式和自动吸附互不影响：无缝模式会让相邻页面连续拼接；自动吸附开启后，滚动停止时会对齐到某一页的起点。术语定义见[项目语境](../CONTEXT.md)。

**电脑端**：鼠标静止 3 秒后，顶栏、信息栏和指针会自动隐藏，移动鼠标即恢复。

**手机端**：可以双指缩放到 1 至 4 倍，放大后单指拖动。在“无缝模式开启、自动吸附关闭”时，屏幕上所有可见页面会一起缩放；其他情况只缩放当前页。双指缩回、双击或点击顶栏的重置按钮可以恢复原尺寸。

## 漫画翻译

1. 在阅读器工具栏或设置面板中打开“漫画翻译”。
2. 填写 OpenAI 兼容服务的 Base URL、模型名称和 API Key，并选择 Chat Completions 或 Responses API。Base URL 应指向 API 根路径，例如 `https://api.openai.com/v1`。
3. 手动翻译当前页，或开启自动翻译。

首次翻译时，浏览器会下载 PP-OCRv5 OCR 模型，之后由浏览器缓存。OCR 在本地运行，只把识别出的文字和文本框位置发送给 LLM，不发送图片。译文会覆盖在原图上，点击单个文本框可以切换回原文。

开启自动翻译后，会优先处理当前页，再按预翻译范围处理前后页面。翻页、切换章节或修改设置后，已经不需要的任务会自动取消。

**思考设置**：“跟随服务”不发送 `reasoning_effort`，“关闭”发送 `none`，“开启”发送所选等级。如果服务不支持所选等级，会直接返回参数错误。

**提示词**：默认模板适用于成人向作品的忠实本地化。可以编辑、清空，或恢复默认。

**API Key 和跨域**：API Key 保存在当前浏览器的 `localStorage` 中，请不要在多人共用的浏览器中保存。默认由浏览器直接请求 LLM 服务，所以服务必须允许跨域请求；如果不允许，可以开启“Worker 代理”，由部署的 Worker 转发请求。

识别结果和译文缓存在 IndexedDB 中，可以在翻译设置中清除缓存，或重新翻译当前页。
