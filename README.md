#

## 需求

### 自动后端域名获取

### 搜索

如果搜索存在的车牌号，结果为仅有对应本子。

搜索对象：本子标题，来源作品，作者，标签，登场人物。

排序：最新，最多点阅，最多图片，最多爱心。

时间筛选：全部，今天，这周，这个月。

分类筛选（次要目标）

### 本子

要查询并展示的内容：标题，作者，标签，封面，所有话。

### 章节

支持下载并解密，以`pdf`，`zip`，或`cbz`格式导出。
